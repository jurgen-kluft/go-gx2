    Controls

    • Drag on empty space to create a new rectangle.
    • Click a rectangle to select it. Drag inside it to move.
    • Ctrl/Cmd-click adds up to 3 ordered selections: main, right reference, down reference.
    • Drag the highlighted handles to resize with the mouse.
    • Arrow keys move by 1 pixel.
    • Shift + Arrow extends the side in that direction by 1 pixel.
    • Press E with exactly 3 ordered selections to expand a sprite grid.
    • Copy/Paste works from buttons or Ctrl/Cmd + C and Ctrl/Cmd + V.
    • Delete or Backspace removes the selected rectangle.
    • Use zoom controls or Alt + mouse wheel for close editing.

    Grid Tool

    Create an adjustable grid and drag each row/column line directly on the image.

    Tip: choose rows/columns, click Select Grid Area, drag an area, then adjust lines if needed.
